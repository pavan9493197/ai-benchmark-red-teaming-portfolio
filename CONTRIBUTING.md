# Contributing / adding new benchmark cases

For every new research benchmark case, record:
1. One precise question with scope, time period, entity, and required output format.
2. A single defensible answer key (or explicit accepted-answer set).
3. A primary source URL whenever possible.
4. A short exact excerpt supporting the answer.
5. Retrieval date and source type.
6. Ambiguity notes, edge cases, and known contradictory sources.
7. Independent verification by a second reviewer where feasible.

Do not copy copyrighted benchmark datasets or claim affiliation with benchmark owners. Create original tasks and cite sources. Do not include private information or attempt unauthorized access.
